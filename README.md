# StridePlan 马术障碍路线设计器

基于 React、TypeScript、Vite、Mantine、Zustand 和 React Router 构建。场地和障碍使用
Canvas 按真实米制尺寸绘制，所有数据保存在浏览器本地。

## 功能

- 标准 60 × 90 米场地、栅格吸附和缩放
- 障碍类型 / 颜色库、编号、旋转、拖动和顺序调整
- 按马匹步幅、接近段、落地段计算推荐步数
- 距离不合理、转角过急和路线交叉实时检查
- 按难度生成三套备选路线并一键应用
- 撤销重做、本地路线库、分享链接
- 可打印路线图和裁判用 CSV 表

### 排场表（路线库 · 器材清单 · 训练场次 同一张表）

在顶部「排场表」页，把路线库、器材清单、训练场次接到同一份排场数据上：

- **按类型与数量预占**：每场选定路线后，按障碍类型聚合数量预占器材；唯一场地作为
  容量 1 的资源与器材统一管理（`src/scheduling/engine.ts`）。
- **先查同时段余量**：新增、复制、改时间或改路线时先检查重叠时段（半开区间，首尾相接不冲突）
  的余量。够则确认并预占；不够则停在「待备料」，明确指出每种资源被哪些场次占用，草稿保留。
- **先交先得**：所有写操作经引擎内串行队列处理，两名教练同时提交抢同一时段时，
  先入队的草稿占用，后者看到占用提示且草稿仍在。开两个浏览器标签页即可复现（跨页 storage 同步）。
- **事务与幂等**：占用以 append-only 账本（hold/release）记录，持有量由未配对 hold 推导。
  器材归还失败或任一场次保存失败时，整场回到提交前；同一提交键重试直接返回首次结论，不重复扣减；
  批量保存任一场冲突则整批回滚。侧栏「故障注入」开关可现场演示。
- **产物按签名失效**：场次时间、场地尺寸、马匹步幅或路线几何改动后，关联场次的安全分析与
  裁判表签名失效、懒重算并标红提示；未受影响的场次照旧。

### 测试

```bash

```

覆盖余量检查、并发先交先得、归还/保存失败回滚、幂等重试、批量原子性、复制改线、
分析/裁判表失效，以及页面 SSR 渲染冒烟。
